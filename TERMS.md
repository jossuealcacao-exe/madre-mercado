# Terms for publishing in MADRE's Market

**In effect since October 28, 2026.**

These terms are between you, who send a module, and me, Jossue Alcalá, MADRE's author, who reviews,
signs and publishes the Market's modules on madre.run. By opening a pull request with a module in
this repository you accept them. This is a translation: if it differs from the Spanish version
(`TERMINOS.md`), the Spanish one prevails.

## 1. Who can send

Anyone of legal age, or a minor with the permission of whoever represents them. If you send a module
on behalf of a company, you state that you can do so for it.

## 2. It is yours

You wrote the code or have the right to publish it. Neither the module nor its entry (name, texts,
icon and screenshots) infringes anyone's rights: copyright, trademarks or trade secrets.

## 3. Its license

You publish the code under the license you state in `spdx`, which must be one of these: AGPL-3.0,
GPL-3.0, MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC or MPL-2.0. Whoever installs your module
receives it from you.

You also allow me to store, copy and distribute your module from madre.run, and to show its entry,
your name and your GitHub user in the Market, inside MADRE and wherever I present the Market.

## 4. What it declares is what it does

The entry and what the module declares (where it connects in `reaches`, which keys it asks for,
which tools it gives the agents and which commands it adds) are true. If your module collects or
sends data about whoever uses it, it declares so and follows the data protection law that applies
to it.

## 5. What is not OK

A module may not:

- carry hidden, obfuscated or minified code: it has to be readable to be reviewed;
- download and run code that is not in its own file;
- mine cryptocurrency, send spam or attack other systems;
- read or send information about whoever uses it without declaring it;
- pretend to be MADRE, one of MADRE's modules or another person;
- carry illegal content.

## 6. Review and signature

I read every module and every new version before signing it. I may accept it, ask you for changes or
not publish it; I am not obliged to publish any module. My signature says I reviewed it, not that it
has no bugs.

## 7. New versions

Whoever installs your module receives its new versions on their own, without accepting it again.
That is why every new version goes through the same review. If a version asks for more than the one
before (another destination, another key or another permission), you say so in `changes`.

## 8. Taking it back

I may take a module or a version out of the Market at any time: if it stops working, does something
it does not declare, breaks these terms, or you ask me to. A module taken back is removed from every
MADRE that has it the next time it reads the Market. To ask me to take yours back, open an issue in
this repository.

## 9. Responsibility

You answer for your module and for what it does. The Market and its community modules are provided
as they are, without warranty of any kind. To the extent the law allows, neither MADRE nor I answer
for what a community module does.

## 10. Free, for now

Community modules are free. Paid ones will come later, with terms of their own.

## 11. Security flaws

If you find a security flaw in a module or in MADRE, tell me privately before making it public, as
[madre.run/security](https://madre.run/en/security/) explains.

## 12. Changes

I may update these terms; if I do, I change the date above. Changes apply to the modules and versions
that arrive afterwards. Questions? Write to me from
[jossuealcala.com](https://jossuealcala.com/en/contact/).
